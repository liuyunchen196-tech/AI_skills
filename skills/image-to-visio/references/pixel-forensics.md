# 像素取证配方 + 两张已验证图的完整几何

## 一、通用配方

### 1. 分层取填充块

```python
g = np.array(Image.open('src.png').convert('RGB')).astype(int).mean(axis=2)
sat = a.max(axis=2) - a.min(axis=2)                 # 排除彩色
mask = (np.abs(g - 199) <= 8) & (sat < 16)          # 目标灰度 ±8
lab, n = ndimage.label(mask)
for i in range(1, n+1):
    ys, xs = np.nonzero(lab == i)
    if len(ys) < 30: continue                       # 滤掉噪点
    print(xs.min(), ys.min(), xs.max(), ys.max(), len(ys))
```

`minpix` 的经验值：实心块 `>= 30`，细长杆 `>= 60`，土壤点 `>= 1`。
**先跑颜色直方图找灰度峰**，再按峰分层——不要凭目测估灰度。

### 2. 逐行 / 逐列扫描找边界

```python
for y in range(0, H, 3):
    xs = np.nonzero(g[y] < 205)[0]
    if len(xs): print(y, xs.min(), xs.max(), len(xs))
```

`x-range` 突变的那一行 = 元素边界。比连通域更快定位"某条横线在 y 多少"。

### 3. 倾斜矩形：按参数化重建，不要用 minAreaRect 的四角

`cv2.minAreaRect` / 最小外接旋转矩形量的是**含描边的外轮廓**。
直接拿四角画线，图形会整体胖约 `lw` 个像素（实测 2.5px）。

```python
t = math.radians(ANGLE)                 # 本机实测：摇摆柱 +8.2~8.4°
u = (math.cos(t), math.sin(t))
v = (-math.sin(t), math.cos(t))
hw, hh = W/2 - INSET, H/2 - INSET       # INSET ≈ lw/2
pts = [(cx + su*hw*u[0] + sv*hh*v[0], cy + su*hw*u[1] + sv*hh*v[1])
       for su, sv in ((-1,-1),(1,-1),(1,1),(-1,1))]
```

**验证方法**：改完后逐行比对 `x` 范围，应吻合到 1px 内。
本项目在 `y=180/200/220/240/255` 五行上逐行验证过。

### 4. 文本行

```python
m = g < 150
lab, n = ndimage.label(m)
comps = []
for i in range(1, n+1):
    ys, xs = np.nonzero(lab == i)
    if len(ys) < 4: continue
    h = ys.max()-ys.min()+1
    if h > 26: continue                 # 排除大结构
    comps.append((xs.min(), ys.min(), xs.max(), ys.max()))
# 按 y 重叠分组，组内按 x 合并 -> 文本行
```

阈值取 150（比结构线用的 205 更严），避免把细线算成字形。
`h > 26` 这个上限按图调整：源图字号越大，上限越高。

### 5. 精确配色

在元素**内部**取样（避开描边），取众数：

```python
sub = a[y0:y1, x0:x1].reshape(-1,3)
u, c = np.unique(sub, axis=0, return_counts=True)
print(u[np.argmax(c)])
```

## 二、迭代收敛判据

| 指标 | 优秀 | 可接受 | 不合格 |
|---|---|---|---|
| 区域 ink 比（复刻/源，`L<200`） | 0.95~1.05 | 0.85~1.15 | <0.80 或 >1.25 |
| 文本字串中心偏差 | < 1 源像素 | < 2 源像素 | >= 3 源像素 |
| 文本墨迹宽度比 | 0.95~1.05 | 0.90~1.10 | 越界 |
| `.vsdx` 往返再导出 | max diff = 0 | — | > 0 |

**文本区域的 ink 比天生只有 0.4~0.6，这是正常的**——源图是缩放过的位图，字形笔画比矢量渲染胖。
不要为了把 0.5 拉到 1.0 而把字加粗或放大；只看位置和宽度。

叠加图读法：红=源、蓝=复刻、黑=重合。
成对的红蓝双线 = 平移偏差；只有红 = 漏画；只有蓝 = 多画。

## 五、从这两张图提炼的"必查清单"

复刻任何一张图，逐项确认：

- [ ] 每个元素都在源图里**亲眼见到**了吗？（样例 A 的 Q3 假虚线就是反面教材）
- [ ] 填充色是取众数还是目测的？
- [ ] 线宽是按源图墨迹宽度反推的，还是随手写的？
- [ ] 倾斜元素是按"中心+角度+内缩"重建的，还是直接用了外接矩形四角？
- [ ] 虚线是矩形短划还是圆点？（决定用手写 `dashed` 还是 `LinePattern=2`）
- [ ] 字号是实测标定的，还是套了字体理论值？
- [ ] 短词（≤4 字母）是不是用宽度反推的？（应改用 cap-height 折中）
- [ ] 有没有任何 shape 越出隐形画框？（`Fig.audit()`）
- [ ] 交付前做过往返校验吗？（重开 `.vsdx` 再导出，max diff 应为 0）
