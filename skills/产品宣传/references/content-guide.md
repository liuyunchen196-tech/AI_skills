# 内容指南：六段式章节骨架与版式选择

标杆范例：`D:\AIproject\项目管理平台\推广材料\content_lean.json`（精益建造宣传，29 页）。
构建 schema 细节见 jituan-PPT 技能的 `references/content-schema.md`。

## 顶层结构

```json
{
  "cover":   {"title": "...", "subtitle": "硬指标串 · 关键词串", "author": "单位 · 部门", "date": "2026年11月"},
  "toc":     {"toc_title": "目录", "items": [{"num": "一", "title": "产品定位"}, ...]},
  "toc_transition": true,
  "sections": [ ...每页一个对象... ],
  "ending":  {"text": "谢谢！"}
}
```

副标题公式：`<N 个硬指标> —— <三个能力关键词>`，如
`91 节工艺 · 231 张标准图 · 3 个分册库自动整合 —— 分部分项导航 · 网页扩充 · 一键发布`。

## 六段式章节骨架（22~30 页）

| 章 | 标题模式 | 页数 | 内容 |
|---|---|---|---|
| 一 | 产品定位 | 2 | 1.1 一句话定位（paragraph）；1.2 谁最需要它（table：角色/痛点/用上之后） |
| 二 | 方法与标准/数据与标准 | 3 | 数据来源流水线（table）、核心结构（bullets_picture 配详情截图）、标准对齐（table） |
| 三 | XX 库/XX 管理 | 3 | 规模统计（table）、怎么扩充/维护（table 或 bullets）、关键技术点（bullets） |
| 四 | 使用流程 | 4 | 四步流程（flow + stages）、2~3 组界面双图（gallery） |
| 五 | 成果形态 | 3 | 每种交付物一页（picture / table） |
| 六 | 应用价值 | 3 | KPI 四卡（kpi）、效率量化表（table）、落地保障（bullets） |

标题编号 `章.序 标题`，如 `2.3 分部分项：整合时自动对齐 GB50300`。
标题里冒号后半句给出"结论"，如 `1.1 一句话：把整柜标准图册变成一个可检索、可扩充的网页`。

## 常用页面 type 选择

| type | 用途 | 关键字段 |
|---|---|---|
| `paragraph` | 一句话定位页，3 段递进（痛点→做法→升华） | `content: [{"para": ...}]` |
| `table` | 角色痛点、规模统计、量化对比 | `content: [[表头,...]]`、`col_widths`（总和≈12.17） |
| `bullets` | 要点罗列（≤6 条，每条一句话+冒号展开） | `content: [...]` |
| `bullets_picture` | 左要点右截图 | `image`、`caption` |
| `picture` | 全宽大图（成果展示） | `image`、`caption` |
| `gallery` | 双图并排（流程对比、两个界面） | `images: [{image, caption}]` |
| `flow` | 工序/使用流程链 | `stages: [{label, steps}]`（自动 Visio 矢量化） |
| `kpi` | 价值总览四卡 | `kpis: [{label, value, unit, desc}]` |

## 写法要求

1. **1.1 一句话定位页**固定三段：
   - 段1：现状痛点（东西早就有，问题是慢/散/难）；
   - 段2：这套工具做的事很直接——（把做法讲成一条流水线）；
   - 段3：它不改变 X，只改变 X 的速度：从「…」变成「…」。
2. **note（底部结论条）**写判断/升华，不重复正文；可用「共同点：…」「一句话概括：…」开头。
   「标签：」前缀会自动加粗。
3. **intro** 一句话引出下面表格/要点（"同一本图册，四类角色拿到的东西不一样。"）。
4. **表格**：首行为表头；单元格 12~24 字为宜；`col_widths` 按内容分配且总和≈12.17。
5. **量化口径**：测算值必须写明样本（"以单个在建项目为测算样本"）并标注保守；
   节省类用区间（−80%、月→天），不写绝对金额承诺。
6. **截图引用**：`image` 写绝对路径；每张图配 `caption`（一行说清"这是什么 + 亮点"）。
7. **章节数与目录条数一致**；每章首页写 `"chapter": N` 触发目录过渡页（当前章标红）。
8. 全稿页数 = 封面 1 + 目录 6 + 正文 18~22 + 结尾 1 ≈ 26~30 页。
