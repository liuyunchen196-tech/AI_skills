# 技能｜PPT配色与排版模板法

> 摘要：一套可复用的演示文稿视觉规范——限色板、60-30-10 配色、两件套字体、网格对齐，让任何页面都"像一套"。

## 适用场景
工作汇报、分享会、课程/培训等一切需要快速产出统一视觉 PPT 的场合；也用于审查他人稿件的版式是否达标。

## 操作步骤
1. **定主色**：选 1 个主题色（品牌色或内容基调色）作主色，配黑/灰中性色，不凭感觉堆色。
2. **60-30-10 配色**：60% 背景用中性色（白/浅灰），30% 主色，10% 强调色（仅用于重点、警示、关键数据）。
3. **限色板**：全篇配色不超过 3 种，色相尽量同族；杜绝红绿蓝黄一页全上的"彩虹稿"。
4. **字体两件套**：标题与正文用同一无衬线家族（如思源黑体/微软雅黑），全篇字体≤2 种；标题≥32pt、正文≥18pt。
5. **层级与对齐**：统一一种对齐方式（左对齐或居中，禁止混用）；用网格/参考线对齐元素，标题、正文、页脚各占固定区域。
6. **留白与模板**：每页留白≥30%，套用统一页眉页脚/封面模板；图表、图标用同色系，不引入第三种视觉语言。

## 注意边界
- 投影环境偏暗时提高文字与背景对比，避免浅灰字配白底。
- 不整页纯黑底白字大段（刺眼、易疲劳）；色盲友好优先蓝/橙，慎用红/绿对比。
- 模板是骨架不是枷锁：内容决定版式，别为套模板削足适履。

## 反例避雷

| 反例 | 为什么错 | 正确做法 |
| :-- | :-- | :-- |
| 一页多种高饱和色 | 视觉噪音，重点被稀释 | 限 3 色，强调色只点关键处 |
| 标题艺术字、正文第三种字体 | 杂乱、显不专业 | 全篇≤2 种字体，同族优先 |
| 元素随意摆放不对齐 | 显廉价、难读 | 用参考线/网格统一对齐 |
| 满页塞字不留白 | 信息过载，抓不住 | 每页留白≥30%，一页一观点 |
