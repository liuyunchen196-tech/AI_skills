# 内容结构与版面规划方法论（F1/F2/F3）

本文件支撑 SKILL.md 的 **F 内容结构与版面规划增强**：金字塔原理（F1）、字体规划（F2）、图文比≤40%（F3）。所有判据均可在 `inspect_pptx.py` 中自动核验。

---

## F1 金字塔原理（结构化叙事）

### 1. 四大底层原则
1. **结论先行（Top-Down）**：每一页的标题本身就是"这一页要传达的结论"，是完整句，不是话题标签。读者扫标题即得 so-what。
2. **以上统下**：页内每个要点都支撑该页的中心论点；论点不溢出本页主旨。
3. **MECE**：要点之间"相互独立、完全穷尽"——不重叠、不遗漏。
4. **纵向疑问 / 横向归纳**：上层是对下层的概括；同层要点按"时间 / 重要度 / 结构 / 因果"之一归类，而非随意罗列。

### 2. SCQA 开场模板（用于封面 / 执行摘要 / 问题页）
- **S（Situation）背景**：当前普遍成立的事实。例："全员每天约 2 小时花在重复文档与信息查询上。"
- **C（Complication）冲突**：现状出了什么问题。例："AI 工具已普及，但多数人只会聊天，不会变成生产力。"
- **Q（Question）问题**：因此要回答什么。例："怎么让非技术同事也用得上？"
- **A（Answer）回答**：本 PPT 的核心结论。例："把 AI 当'同事'：今天上手、持续练习、交流分享。"

### 3. Action Title（结论式标题）写法
- ✅ 结论式："用 AI 把重复活干完，腾出手做值钱的事"（含动词 + 结果）。
- ❌ 话题式："AI 应用概述""案例分析""工作总结"（只点题不点论）。
- 长度：≤15 词（英文 ≤12 words）。避免"关于……的探讨"这类名词短语。

### 4. 自动检测对照（`inspect` PYRAMID / ACTION-TITLE AUDIT）
| 检测项 | 判定规则 | 修复 |
|---|---|---|
| Action-Title 占比 | 标题含断言动词（是/让/用/能/提升…）或句号/问号/感叹号结尾 → 计为结论式 | 占比 <80% 时，把话题标题改写为结论句 |
| 话题式标题清单 | 命中 TOPIC_LABELS（概述/背景/案例/总结…）或无动词无结尾标点 | 逐条改写 |
| 全局结论 | 封面副标是否含结论句（点题） | 补一句话全局结论 |

## F2 字体规划（Font Plan）

### 1. 角色化字体规划表（全篇唯一标尺）
| 角色 Role | 字体 | 字重 | 字号(pt) | 字色 | 行距 / 字距 |
|---|---|---|---|---|---|
| Display 封面主标 | 微软雅黑 | Bold | 40–48 | 深蓝/白 | 字距 +0.8 |
| Title 内容页标题 | 微软雅黑 | Bold | 30–36 | 深蓝 | 字距 +0.6 |
| Subtitle 副标 | 微软雅黑 | SemiBold | 18–24 | 灰 | — |
| Body 正文 | 微软雅黑 | Regular | 14–18 | 近黑(#222) | 行距 1.2–1.5 |
| Caption 图注 | 微软雅黑 | Regular | 12–13 | 灰(#666) | — |
| Footer 页脚 | 微软雅黑 | Regular | 10–11 | 浅灰(#999) | — |
| Kicker 章节标签 | 微软雅黑 | Bold | 11–12 | 强调色 | 字距 +0.3，大写感 |

### 2. 铁律
- 全篇 ≤2 字族；本例统一 微软雅黑。
- 同角色跨页完全一致（标题页页同字号同字重同色）。
- 标题与正文字重差 ≥1 级（靠字重而非全边框拉层级）。
- 字号落在 10–60pt 规划带；`inspect` FONT PLAN 段会列出实际分布并标离谱值。

### 3. 套用方式（`fix_pptx.py --apply-font-plan`）
- 规划文件为 JSON：`{"rules":[{"role":"Title","when":{"slide":"content","size":"largest"},"size":30,"bold":true,"color":"1F3864","name":"微软雅黑"}, ...]}`。
- **按位置/字号匹配，不依赖关键词**：每个 run 由 `scripts/fontplan.py` 按 `when` 里给出的维度（zone 版面区域 / slide 页序 / size 标题带内最大 / pagenum 页码 / 可选 match 关键词）自上而下取**首个全维度命中**的规则套用。默认规划零关键词即可直接用。
- **判定要点**：
  - `size:"largest"` 仅在**顶部 30% 标题带**内取最大字号，因此底部大号装饰数字 / 统计数字不会抢占「标题」角色；
  - `when.pagenum:true` 锁定「纯数字 + 位于页脚/页眉角」的 run 为真实页码（Footer），与步骤号（如「1/2/3/4」）区分；
  - `Body` 角色**不写 size**，只统一字族/字色，保留稿内原有正文字号层级（非破坏性默认）。
- 典型顺序：先 `--normalize-font` 统一字族，再 `--apply-font-plan` 落实字号/字重/字色层级。
- 套用前可用 `inspect_pptx.py` 的 `FONT PLAN ROLE MAP` 预览角色分布，核对命中是否合理。
- 完整示例见 `references/font-plan.default.json`（零关键词、纯位置/字号规则）。

## F3 图文比 ≤40%（视觉占比）

### 1. 原则
- 文字为主、图像为辅；**单页图片占用面积 ≤ 幻灯片总面积 40%**。
- 0 图纯字墙页：关键页（封面/核心论点）可考虑图示化，但非强制。
- 分级：≤30% 优 / 30–40% 可接受 / >40% 偏图需修。

### 2. 测算（`inspect` IMAGE-TEXT RATIO）
```
单页图文比(%) = Σ(图片形状宽 × 高) / (幻灯片宽 × 高) × 100
```
仅统计 `MSO_SHAPE_TYPE.PICTURE`；背景填充、图标形（非 PICTURE）不计入。

### 3. 超占比修复手法
- 去背景大图，改深色/浅色色块或渐变承载标题（更"人工"、更聚焦）。
- 图缩至一侧（左图右文 / 右图左文），另一侧放要点。
- 关键图保留，其余信息转文字要点或原生图表（去装饰网格）。
- 一页图太多 → 拆页，每页一个焦点。

## 综合判级建议（与五维评分联动）
- 结构逻辑维度：金字塔 Action-Title 占比 ≥80% 且 全局结论存在 → 该维可评 4+。
- 视觉呈现维度：图文比全篇 ≤40% 且 字体规划 conformance 通过 → 该维可评 4+。
- 任一硬伤（话题式标题 >40% 内容页 / 图文比 >40% 多页）降为 P1/P2 打磨项。
