# 版面与字体设计准则（评估/修复标尺）

> 调研来源：麦肯锡/BCG/Bain 咨询幻灯片规范（Gamma、Deckary、SlideSpeak）、上海交大官方字体层级、PPT 排版黄金法则（pptwiki/猪八戒/ufcn）、中英文字体搭配权威站（ima 知识库、zhengruan、slidesai、a1slides、tsight 告别廉价感）。本准则解决"看起来粗糙"的根因——**排版逻辑失衡 + 字号过小 + 字体层级缺失**，而非堆素材。

## D1 网格与对齐（消除漂浮感）
- 16:9 采用 **3 栏或 12 列隐形网格**；统一页边距：左右各 ≥10%（约 0.6–0.9in），正文区宽度一致。
- 所有元素（标题/卡片/图标/图表/页码）严格对齐到网格；**同类型元素全篇对齐方式一致**（如标题左对齐、页码右上角徽标）。
- 每页只允许 **1 个视觉焦点**（标题或核心图/数据），其余降为辅从。
- 模块间距用"留白"而非回车堆行；标题与首行正文间距 ≥ 标题高度。

## D2 留白（高级感的关键）
- 每页留白面积 **≥30%**；左右各预留 12–15% 空白，不放置文字/图形。
- 信息密度：每页 ≤6 行要点，每行 ≤12 汉字（6×6 法则）；关键数据/结论单独成行放大+色块衬底。

## D3 字体系统（核心，专治"廉价感"）
- **数量**：全篇 ≤2 种字体族（标题 + 正文），最多 3 种；严禁 宋+黑+艺术字 混搭。
- **中文商务首选（按安全/气质排序）**：
  - 微软雅黑 Bold（标题）+ 微软雅黑 Regular（正文）——**最安全、零缺失风险**（系统自带，免嵌入）；
  - 思源黑体 Bold（标题）+ 思源黑体 Light/Regular（正文）——同族字重对比，更"大气"（需安装或嵌入）；
  - 思源宋体/方正小标宋（标题）+ 思源黑体/微软雅黑（正文）——权威/正式感（报告、金融、法律）。
- **字号阶梯（投影/屏幕通用，单位 pt）**：
  | 层级 | 推荐 | 最小 |
  |---|---|---|
  | 封面主标题 | 40–48 | 36 |
  | 内容页 Action Title | 32–36 | 28 |
  | 副标题/小标题 | 24–28 | 20 |
  | 正文/要点 | 18–24 | 16 |
  | 图注/标签 | 14–16 | 12 |
  | 页脚/页码 | 10–12 | 9 |
- **层级靠字重不靠混字**：标题 Bold/Heavy、正文 Regular、强调 Medium；用 **字重 + 字号 + 颜色** 三级对比建立层级，避免全页同字号。
- **行距**：正文 1.2–1.5×；标题 1.0–1.2×；段距 > 行距。
- **字间距（tracking）**：标题过大时微调加宽（如 +0.3~0.8pt）提升"大气感"与可读性。
- **对比度**：文字 vs 背景 ≥4.5:1（深底浅字 / 浅底深字）。
- **嵌入**：用系统字体（微软雅黑）规避缺字；自定义字体（思源黑体等）必须「文件→选项→保存→嵌入字体」，否则换机演示排版崩塌。
- **强制统一**：修复时用 `fix_pptx.py --normalize-font "微软雅黑"` 将全篇 run 统一为指定字体（同时写 latin+ea，消除中文混搭/缺字）；评估时用 `inspect_pptx.py` 的 FONT UNITY 行核验字族数 ≤2。

## D4 配色（60-30-10）
- 主色 60%（标题/底色/大面积）、辅色 30%（图表/图标/卡片）、强调色 10%（关键数据/行动项/警示）。
- 最多 3 主色（含语义红/绿可放宽至 4）；商务首选沉稳深蓝 + 1 个强调（橙/青）+ 中性灰；**避免高饱和荧光色**，低饱和更显高级。
- 强调色只用于"最该被看见的一项"，其余降为灰阶。

## D5 信息层级与 Action Title
- 每页一念（one message per slide）；标题即结论（完整句、≤15 词、主动语态），非话题标签。
- 关键数据单独成行放大 + 色块衬底；"所以呢（so what）"用一句话点透。

## D6 视觉质感与图表
- 渐变/阴影克制使用（卡片浮起、标题色条、强调块）；图标风格统一（线性/面性、同色系）。
- 图表原生：去网格线/图例、系列直接标注、强调色只标关键项、其余灰阶；配基线/刻度。

## D7 版面体检清单（修复/评估时逐项查）
1. [ ] 每页标题为唯一 Action Title，字号 ≥28pt 且加粗；
2. [ ] 正文 ≥16pt、行距 1.2+，无大段堆字；
3. [ ] 全篇字体 ≤2 种，标题/正文靠字重区分（inspect FONT UNITY 复核）；
4. [ ] 左右页边距一致 ≥10%，留白 ≥30%，无元素贴边/越界（inspect OUT-OF-BOUNDS 复核）；
5. [ ] 配色 ≤3 主色，强调色仅用于关键项（inspect COLOR HUE FAMILIES 复核）；
6. [ ] 所有元素对齐到网格，同类型对齐方式全篇一致；
7. [ ] 每页 1 个视觉焦点，无装饰噪音；
8. [ ] 页码/章节标注正确、对比度 ≥4.5:1、无缺字风险（系统字体优先）。
