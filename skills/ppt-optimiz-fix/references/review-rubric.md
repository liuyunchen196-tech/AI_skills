# PPT 优化修复顾问 · 复评与评估细则（review-rubric）

> 本细则整理自 `pptx-deck-evaluation` 技能的评估方法论，作为本技能 **§2 质量评估** 与 **§10 复评与多轮闭环** 的精细评分与报告模板参考。
>
> **评分刻度说明**：本细则采用 **10 分制** 精细锚点；与本技能 §2 的 **1–5 分制** 可线性映射（10 分制 ÷ 2 ≈ 1–5 分制，例如 9–10≈5、7–8≈4、5–6≈3、<5≈≤2）。两者任选其一，对外报告建议统一用一种，并在报告头部注明所用刻度。

## 一、五维度评分细则（各 10 分）

评分时每个维度先收集证据（具体页/具体发现），再打分；锚点如下。

### 1. 结构逻辑（Storyline）
| 分数带 | 锚点 |
|---|---|
| 9-10 | 结论先行、金字塔叙事，「Why—What—How—Next」认知链完整；只读标题即成故事；章节分隔与回顾页节奏清晰 |
| 7-8 | 认知链完整但有瑕疵：标题偏「主题式」而非「论断式」；个别章节顺序失配；回顾页与内容不一致 |
| 5-6 | 结构松散或拼装感明显：多套模板混排、章节断裂、前后矛盾 |
| <5 | 无清晰主线，逻辑跳跃 |

典型问题：政策科普挤占前 5-8 分钟、核心成效与 ROI 过半才出现、章节页/回顾页缺失或错位。

### 2. 内容深度（Content Depth）
| 分数带 | 锚点 |
|---|---|
| 9-10 | 一手量化数据 + 外部权威引用 + 标杆案例三角齐备，数据新鲜且可溯源 |
| 7-8 | 内容资产扎实，但有占位符、重复句、复制粘贴错误、数字矛盾等硬伤 |
| 5-6 | 以通用表述为主，缺自有数据与可验证证据 |
| <5 | 空泛口号或信息过时 |

典型问题：「（请以贵司试点实测填入）」占位符、同一数据两页重复、「五步/四步」表述不一致、删页后回顾页仍引用已删内容。

### 3. 受众适配（Audience Fit）
| 分数带 | 锚点 |
|---|---|
| 9-10 | 内容密度与叙事节奏匹配目标受众决策链，管理者视角（ROI/风险/落地路径）全覆盖 |
| 7-8 | 大体匹配但局部错位：承诺与证据落差（如面向制造业却只有后台案例）、专业术语未分级 |
| 5-6 | 受众画像不清，或关键决策问题未回答 |
| <5 | 通篇自嗨，受众无法带走任何决策依据 |

典型问题：制造业专场却无制造核心场景自有案例、结尾无 CTA、关键页（ROI）反而最未完成。

### 4. 视觉呈现（Visual Presentation）
| 分数带 | 锚点 |
|---|---|
| 9-10 | 统一模板体系，图表规范，无折行/裁切/重叠/溢出 |
| 7-8 | 整体统一但有局部缺陷：个别页折行、裁切、截图不可读 |
| 5-6 | 多套模板混用、字体杂乱（>6 类）、页码断序 |
| <5 | 大量元素互叠、投影不可读 |

典型问题：年份/百分号折行、标题副标题重叠、卡片文字裁切、外来模板页、页脚与页码断序（如 37/39/40/41/38）、结尾页半页留白。

### 5. 说服力（Persuasiveness）
| 分数带 | 锚点 |
|---|---|
| 9-10 | 证据链闭环：痛点→方案→量化收益→风险应对→行动号召，金句有力 |
| 7-8 | 证据齐全但未收口：无 CTA、收益页留占位符、案例与主张错位 |
| 5-6 | 主张多、证据少，或关键收益无法量化 |
| <5 | 无证据、无行动指引 |

### 综合分
取五维加权（可均权）并注明一句话定性，如「内容资产优秀、工程化不足」。

## 二、硬伤速查表（报告必含）

表格字段：`页码 | 问题类型 | 问题描述 | 严重度(P0/P1/P2) | 证据(截图/文本位置)`。
按严重度排序，同一页多问题合并为一行或分行列出。

## 三、P0/P1/P2 优先级定义

- **P0（文字硬伤，立即可修）**：占位符、错别字、重复句、复制粘贴错误、数字矛盾、页码断序、标题折行裁切。一次编辑会话即可清空，不涉及版式重做。
- **P1（结构与视觉迭代）**：删除/重绘低价值页（如不可读截图）、叙事顺序调整、模板统一、压缩页数、结尾补 CTA。
- **P2（策略级）**：内容资产补强（补制造核心场景自有案例）、受众分层、长期叙事升级。

## 四、报告模板（Markdown 结构）

```
## 《{deck名}》专业评估报告（{轮次，如：复评/第三轮复评}）

评估对象：{文件名、页数、更新于何时}
目标受众：{受众描述}
评估方法：{全文审读 + 逐页视觉审查 + 结构化 QA（N 项发现 / M blocking / K 警告）+ 同类优秀实践对标[+ 逐条核对前 N 轮问题清单]}

### 一、{版本对比 | 总体评价与评分}
{复评时：修对的 N 项 / 未动的老问题 / 新引入的问题；初评时：总体评价段落}
### 二、五维度评分与详评
{结构逻辑 / 内容深度 / 受众适配 / 视觉呈现 / 说服力 各小节：分数 + 证据 + 亮点 + 问题}
### 三、硬伤速查表
{表格}
### 四、改进建议（P0 / P1 / P2）
{按优先级分组，每条含页码与具体动作}
### 五、问题流转表（仅多轮复评）
{表格：问题 | 提出轮次 | 各轮状态(未动/修复/新引入) | 最终状态}
```

## 五、常用检查启发式

- **占位符/未完成标记**：grep「请以」「待填」「XXX」「TODO」「示例」。
- **重复句/复制粘贴错误**：`text.count(特征串)` 跨页计数；单页内同一句子出现 ≥2 次即重复。
- **数字矛盾**：同一数字/表述在不同页不一致（如「五步」vs 图上 4 步、「四步法」但列 5 项）。
- **页码断序**：逐页提取纯数字文本，检查序列跳变/重复；注意区分章节号（01/02）与页码；以目检为准。
- **删页一致性**：回顾页/总结页引用的内容页若已删除，即为「翻页即被抓包」的矛盾，复评必须专项核对。
- **字体统计**：inspect_report 中字体种类 >6 提示模板拼装；外来模板页常表现为页脚/标题栏/配色突变。
- **QA 豁免**：章节分隔页 watermark overlap 剔除；剩余 blocking 才计入真实视觉缺陷。

> 注：本技能用 `inspect_pptx.py` 的结构化审计（越界 / 配色族数 / 图文比 / 字体统一度）等价覆盖上述视觉 QA 要点，无需外部 `qa_pptx.py`；若确有 `qa_pptx.py` JSON，`title_diff.py --qa` 可直接复用。

## 六、复评问题流转表模板

```
| 问题（页码+简述） | 提出轮 | 首评 | 复评 | 第三轮 | 最终 |
| --- | --- | --- | --- | --- | --- |
| P36 ROI 占位符 | 首评 | ✗ | ✗ | ✓ 修复 | 已修 |
| P16 结论重复 | 首评 | ✗ | ✗ | ✗ | 未修 |
| P38 错别字「方法法」 | 第三轮 | - | - | ✗ 新引入 | 新引入 |
```

「净效果」判断：修对数量 vs 删错/新增数量，给出「净效果为正/负」结论。
