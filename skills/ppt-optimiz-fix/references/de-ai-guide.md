# 去AI味（人工化润色）方法论

> 适用：让 AI 生成的 PPT 在**视觉**与**文案**两层都呈现"人工打磨"质感，消除典型 AI 痕迹。
> 配套：`scripts/ai_tells.py`（词库+扫描器）、`scripts/inspect_pptx.py`（AI 味体检）、`scripts/deai_pptx.py`（修正要点报告）。

---

## 一、AI 味的来源（为什么一眼假）

生成模型偏好：均衡、安全、高频词、模板结构、完整排比、无害套话。观感信号：

| 层 | 典型信号 |
|---|---|
| 界面 | 版式千篇一律、配色过度饱和且绝对均匀、元素严格等分对称、全边框卡片堆叠 |
| 文案 | 过渡句机械、黑话套话堆砌、排比过度工整、案例"假设化"、数据无来源 |

---

## 二、界面去AI化（视觉人工质感）

**6 条原则（打破"生成器审美"）**

1. **打破绝对对称**：主从不对称、故意留白偏移、元素非等分；让画面有"人手摆过"的痕迹。
2. **版式有节奏变化**：同章节内页与页之间微调（卡片数、位置、占比、图文左右互换），避免"换汤不换药"。
3. **配色有呼吸**：60-30-10 故意倾斜（主色并非精确 60%）；强调色只点一处；掺入低饱和"脏"色增加真实感；避免荧光感纯色。
4. **字体有性格**：标题用一款有特征的中文字体（思源宋体 / 站酷系列）做点睛，正文仍用安全字体；字重对比拉大；标题紧字距、正文松行距，对比有意为之。
5. **细节有手作感**：图标非纯几何、配图带质感阴影、分隔线非贯穿、页码/标签位置微变化、加入真实截图或批注感元素。
6. **层级靠对比而非靠框**：少用全边框卡片，多用留白 + 对齐 + 字号建立层级。

**检测点**：`inspect_pptx.py` 计算每页"版式签名"（矩形/文本块/椭圆数量元组），若 >70% 内容页签名一致 → 判为模板感重，需注入版式变化。

---

## 三、文本去AI化（文案人工质感）

### AI 味体检清单（按严重度）

**P0 硬痕迹（单页出现即红）**
- 机械化过渡句：`总而言之 / 综上所述 / 值得注意的是 / 毋庸置疑 / 不可否认 / 显而易见 / 在当今…时代 / 随着…的发展 / 首先…其次…再次…最后 / 一方面…另一方面`
- 黑话套话堆砌：单页 ≥3 个 → `赋能 / 打造 / 一站式 / 闭环 / 抓手 / 颗粒度 / 底层逻辑 / 范式 / 护城河 / 组合拳 / 方法论 / 落地 / 对齐 / 痛点 / 爽点 / 引爆 / 颠覆 / 重塑 / 生态 / 飞轮 / 链路 / 矩阵 / 第二曲线`

**P1 软痕迹**
- 过度工整排比：≥3 条要点字数/结构高度一致（像生成器凑齐）
- 空洞抽象：通篇 `提升效率 / 优化体验 / 创造价值 / 实现价值` 无具体主语/数字/场景
- 千篇一律模板感：每页同结构（图标圆+三栏+总结句），叙事无起伏

**P2 打磨项**
- 过渡句机械、案例"假设化"（`例如某企业通过…`）、数据无来源/无单位

### 改写手法（去AI味六法）
1. **砍过渡句**：删 `综上所述` 类，用结论直接衔接；段间用 `但是/所以/换个角度` 等真实逻辑词。
2. **破排比**：工整三/四条改 2+1 或长短交错，留最重要一条，其余并入。
3. **给具体**：`提升效率` → `把周报从 3 小时压到 20 分钟`；`某企业通过` → 真实场景或带细节的可替换占位。
4. **换人话**：黑话→口语化业务词；`赋能业务` → `让销售少做重复活`。
5. **加视角**：加入 `我们踩过的坑 / 一个反例 / 现场提问` 等真实感元素。
6. **叙事有起伏**：先抛问题/冲突，再给解法，结尾留悬念或行动，而非平铺直叙。

### 前后对照示例

| 维度 | Before（AI 味） | After（人话） |
|---|---|---|
| 过渡 | 综上所述，AI 赋能将重塑企业生产力。 | 所以真正要做的，是把重复活交给 AI，人去做判断。 |
| 排比 | 提升效率、优化体验、降低成本、创造价值。 | 最直接的收益是：销售每周少填 4 张表。 |
| 黑话 | 打造一站式闭环生态，沉淀方法论。 | 把报名、审核、发通知三步合到一个表里。 |
| 案例 | 例如某企业通过 AI 实现了降本增效。 | 我们试过：用 AI 写周报，从 3 小时降到 20 分钟。 |
| 数据 | 效率得到显著提升。 | 客服响应从 8 分钟降到 90 秒（内测数据）。 |

## 四、输出：去AI味修正要点（必含两类）

报告（`deai_pptx.py`）必须明确覆盖：

- **A. 界面风格优化要点**：位置（页/区域）/ 问题（模板感/对称/配色均匀）/ 改法。
- **B. 文本去AI化要点**：位置（页）/ 类型（过渡句/黑话/排比/空洞）/ 原句 / 建议改写。

两类缺一不可，确保"视觉 + 文案"双线去 AI 味。
