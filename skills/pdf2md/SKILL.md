# PDF转Markdown 文档解析 文本提取

## 一、能力边界：一页纸速查卡

本技能专注于将 PDF 文件内容转换为结构化的 Markdown 文本，适用于学习笔记整理、资料归档、内容二次创作等场景。

| 维度 | 说明 |
|------|------|
| **核心输入** | 本地 PDF 文件路径、可访问的 PDF 文件 URL |
| **核心输出** | 结构清晰的 Markdown 文档（.md 文件） |
| **处理范围** | 文本提取、基础格式保留（标题、段落、列表）、表格识别（尽力而为） |
| **处理上限** | 单次处理文件不超过 50MB；单文件页数不超过 200 页 |
| **处理耗时** | 单文件平均 5-15 秒（视文件复杂度而定） |

### ✅ 能做（5 项核心能力）

1. **文本层提取**：从数字型 PDF 中准确提取文字内容，保留段落结构。
2. **基础格式映射**：识别标题层级（H1-H4）、粗体、斜体、列表项，并映射为 Markdown 语法。
3. **表格结构识别**：对规则表格进行行列解析，输出为 Markdown 表格格式（准确率约 85%）。
4. **批量处理支持**：支持同一目录下多个 PDF 文件的批量转换，输出文件自动命名。
5. **URL 直接解析**：输入公开可访问的 PDF 链接，技能自动下载并处理。

### ❌ 不能做（明确边界）

| 限制项 | 说明 |
|--------|------|
| **扫描件 OCR** | 纯图片型 PDF（扫描件）无法直接提取文字，需用户先进行 OCR 预处理 |
| **复杂版面还原** | 多栏排版、图文混排的精确还原能力有限，可能丢失部分布局信息 |
| **手写内容识别** | 不支持手写文字的识别与转换 |
| **加密 PDF** | 需要密码的 PDF 文件无法处理，需用户先解除密码保护 |
| **公式精确转换** | 数学公式、化学方程式等特殊符号可能转换为近似文本，不保证精确 |

2. **网络访问**：若需使用 URL 直接解析功能，确保运行环境可访问目标 PDF 链接。
3. **文件系统权限**：具备读取本地 PDF 文件及写入输出 Markdown 文件的目录权限。
4. **可选依赖**：若 PDF 中包含复杂表格，建议安装 `pdfplumber` 或 `camelot` 库以增强表格识别效果；若需处理扫描件，需自行配置 OCR 工具（如 Tesseract）进行预处理。

配置步骤：将本 Skill 文件放置于 WorkBuddy 的 skills 目录下，重启 WorkBuddy 即可自动加载。无需额外注册或激活操作。

## 使用方法

使用本 Skill 的完整流程如下：

1. **触发技能**：在 WorkBuddy 对话中输入触发词，如“PDF转Markdown”“PDF文字提取”“PDF解析”等，即可激活本技能。
2. **提供输入**：明确告知需要转换的 PDF 文件路径（本地路径）或可公开访问的 URL 链接。
3. **确认参数**（可选）：如需自定义输出格式，可指定以下选项之一：
   - 纯文本输出（无格式标记）
   - 完整格式输出（默认，保留标题、列表、表格等）
   - 带元数据输出（额外包含文件信息、页数、提取时间等）
4. **等待处理**：技能将自动执行文件检查、内容提取与格式映射，单文件平均耗时 5-15 秒。
5. **获取结果**：转换完成后，输出 Markdown 文件将保存至当前工作目录，文件名与源 PDF 同名（扩展名为 `.md`）。
6. **批量操作**：如需转换多个文件，可将所有 PDF 放入同一目录，并告知技能“转换当前目录所有 PDF”，技能将自动遍历处理并逐一输出。

## 示例

**示例 1：单文件转换（本地路径）**

用户输入：`将 /Users/me/Documents/report.pdf 转为 Markdown`

技能输出：在当前目录生成 `report.md`，内容包含：
- 文档标题（映射为 `#` 一级标题）
- 章节标题（映射为 `##`、`###` 等）

- 列表项（映射为 `-` 或 `1.` 格式）
- 规则表格（映射为 Markdown 表格语法）

**示例 2：URL 直接解析**

用户输入：`解析 https://example.com/sample.pdf 并转为 Markdown`

技能输出：自动下载该 PDF 至临时目录，完成解析后生成 `sample.md`，并在文档末尾附注来源 URL 与下载时间。

**示例 3：批量处理**

用户输入：`将当前目录所有 PDF 转为 Markdown`

技能输出：遍历当前目录下所有 `.pdf` 文件，逐个转换并生成同名 `.md` 文件，处理完成后汇总报告每个文件的转换状态（成功/失败/跳过）及耗时。

## 常见问题

**Q1：转换后的 Markdown 中表格格式错乱怎么办？**

A：本技能对规则表格的识别准确率约为 85%，复杂表格（如合并单元格、嵌套表格）可能出现行列错位。建议在转换前对源 PDF 进行简化处理，或转换后手动调整表格部分。若表格为图片形式，需先进行 OCR 预处理。

**Q2：为什么扫描件 PDF 无法提取文字？**

A：扫描件本质是图片集合，不包含文本层。本技能明确不支持扫描件 OCR，需用户先使用 OCR 工具（如 Adobe Acrobat、Tesseract）将扫描件转为可搜索 PDF 后再进行转换。

**Q3：加密 PDF 如何处理？**

A：需要密码的 PDF 文件无法直接处理。请先使用 PDF 解密工具（如 qpdf、Adobe Acrobat）解除密码保护，再使用本技能进行转换。

**Q4：单文件超过 50MB 或 200 页怎么办？**

A：本技能设定了处理上限（50MB/200 页），超出限制的文件将被拒绝处理。建议将大文件拆分为多个小文件后分别转换，或使用专业 PDF 工具先行压缩。

**Q5：转换结果中出现了“低置信度”标注是什么意思？**

A：当技能在提取过程中遇到无法确定的内容（如模糊字体、异常排版、特殊符号）时，会按照“不编造原则”在对应位置标注低置信度提示，而非强行输出错误内容。用户可根据标注手动核对原文。

**Q6：批量处理时部分文件失败怎么办？**

A：技能会为每个文件生成独立的处理状态报告。失败原因通常为文件损坏、加密、超限或格式异常。请根据错误码定位问题文件，修复后重新执行转换。

## 简介

PDF转Markdown 文档解析与文本提取：将PDF文件高效转换为结构化Markdown，保留关键信息与格式。。
核心能力覆盖：维度（说明）；**核心输入**（本地 PDF 文件路径、可访问的 PDF 文件 URL）；**核心输出**（结构清晰的 Markdown 文档（.md 文件））。
用户说「PDF转文档」即可触发。本 Skill 将上述能力封装为可执行脚本与结构化输出，开箱即用，无需额外配置环境。
