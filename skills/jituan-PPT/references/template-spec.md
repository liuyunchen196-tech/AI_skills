# 集团模板规格说明书（来自 D:\AIproject\模板.pptx 实测）

> 本文件是「jituan-PPT」技能的数据基础。构建脚本 build.py 已内置全部关键坐标；
> Agent 需要手工微调或排查问题时参考本规格。不要改动 build.py 中与本节冲突的常量。

## 1. 画布

- 尺寸：**16:9 宽屏**，13.333 × 7.5 英寸（12192000 × 6858000 EMU）
- 主题色方案：
  - accent1（主蓝）：`#0070BF`
  - accent2（亮绿）：`#8CC121`
  - dk1：`#000000`，lt1：`#FFFFFF`
  - 标题字体 majorFont：Calibri Light；中文字体实际使用：**微软雅黑**
- 版式清单（唯一母版下 7 个版式）：
  | 版式 | 占位符 | 用途 |
  |---|---|---|
  | 标题幻灯片 | 标题 + 3 个正文占位符 | 封面/结束页 |
  | 目录_单栏 | 无标题，左侧编号装饰 | （备选目录，暂不用） |
  | 标题_内容 | 标题 + 正文 | **所有正文页使用** |
  | 目录_双栏 | 标题 | （备选，暂不用） |
  | 1_空白 | 标题 | 通用空页 |
  | 空白 | 无 | 全空白 |
  | 1_标题_内容 | 标题 | 备用 |

**关键规则（勿「重新绘制」目录页）**：

1. 目录页版式固定，`build.py` 采用**整页克隆模板原型**的方式生成（保留阴影、曲线、装饰、占位符），只替换文字；
2. **每章正文之前插入一页目录**，当前章标题条整条标红 `#FF0000`（20pt，不加粗），其余条目文字统一白色 `#FFFFFF`（蓝底标题条上清晰，v1.4.2）；模板中「第2页目录=第1章红 → 第1章正文 → 第3页目录=第2章红 → …」；
3. 条目数可变（1~10）：<5 条删除多余条目；>5 条复制末条并沿原曲线等距插值（装饰曲线本身不延长）；>10 条截断告警；
4. 目录页的正文条目**不带编号数字前缀**（数字由左侧编号方块承担），模板占位文案「目录N标题」必须整体替换为章标题。

## 3. 风格规则（正式集团 PPT 硬性要求）

- **字体统一微软雅黑**（标题/正文/表格/编号全部），西文 Calibri
- **字号规范（v1.4 硬性）**：正文 16 号；表格 14 号；页标题 24 号；目录条目 20 号（模板固定）；封面 34 号。正文/表格不再自适应缩字号
- **色板**：蓝 `#0070BF`（主）、亮绿 `#8CC121`（强调）、深灰 `#262626`（正文）、中灰 `#606060`（次要）、红 `#FF0000`（当前章/警示只用）、浅蓝底 `#EEF4FA`（斑马纹）
- **表格即正式**：任何数据必须用表格呈现，禁用自由散排的一行一框
- **流程图矢量规范（v1.4）**：`flow` 版式用 Visio COM 生成 `.vsdx` 并导出 EMF 矢量图插入 PPT（`scripts/flow_to_visio.py`）。样式基准 `C:\Users\liuwust\Desktop\PPT\素材\设计后期管理流程.vsdx`：
  - 流程步骤节点：直角矩形，填充 `#eceef6`，边框 `#3d64ac` 0.75pt
  - 阶段标签节点：直角矩形，彩色填充循环（`#b4a7d6`/`#f9cb9c`/`#ff9999`/`#b5c7e7`/`#99dfb9`），边框 `#fe4040` 红色虚线 1pt
  - 文字：微软雅黑加粗 12pt 黑色居中（v1.4.2 起与全稿统一，不再用基准文件的宋体）
  - 连接线：黑色 0.75pt 实心三角箭头（EndArrow=4）；阶段标签沿左列竖排、竖线串联
  - `.vsdx` 与 `.emf` 均保留：EMF 插入 PPT 无损缩放，VSDX 供后续在 Visio 中再编辑
- **图片**：等比缩放不拉伸，细灰边框（#C0C0C0 0.75pt），图下可加居中灰色小字说明
- **对齐**：正文页内容不越过 T1.35；页脚区域（T7.0 以下）不要放内容
- **目录章数自适应**：条目数 1~10 可增减；≤5 条用模板实测位置，>5 条沿原曲线等距插值，>10 条截断并告警
- **每章一页目录**：章节正文前插入目录页，当前章标题条整条标红，格式为模板固定版式（克隆原型，不重绘）

## 4. 已知限制

- build.py 生成的是「新版式风格」页面；模板自带的旧版式（目录_单栏/双栏）未复用
- 目录页采用克隆原型，装饰曲线固定为 5 个位置；6~10 条时条目会沿纵轴延展到曲线末端之外（曲线本身不延长）
- 模板自带示例页会在生成时自动清除，仅保留目录页原型用于克隆
