# PPT大挪移 - PPT Style Transfer

## 核心理念

把"内容PPT"的内容完整迁移到"模板PPT"的视觉样式中，实现一键美化。不是简单复制粘贴，而是深度样式融合——保留原PPT的所有文字、图片、图表、数据，同时套用模板PPT的版式、配色、字体、背景、图形样式等视觉设计。

## 工作流程

### 第一步：读取与识别双PPT

1. 读取用户提供的两个PPT文件：
   - **A-PPT（内容源）**：包含需要保留的内容（文字、图片、图表、数据）
   - **B-PPT（模板源）**：包含需要套用的视觉样式（版式、配色、字体、背景）
2. 全局扫描两个PPT：
   - A-PPT：页数、内容结构、媒体元素（图片/图表/视频）、动画效果
   - B-PPT：母版数量、版式种类、主题颜色方案、字体方案、背景样式
3. 向用户确认映射关系：
   - 如果A和B页数相同 → 按页一对一映射
   - 如果A页数多于B → 提示用户选择：重复最后一页版式 / 按比例分配版式
   - 如果B页数多于A → 只用B的前N页版式（N=A的页数）
   - 询问用户是否需要迁移动画效果（默认不迁移）

### 第二步：提取B-PPT模板样式

从B-PPT中提取以下样式维度：

#### 1. 幻灯片母版（Slide Master）
- 母版背景（纯色/渐变/图片/纹理）
- 母版占位符布局（标题、正文、页脚、页码、日期）
- 母版上的固定图形元素（Logo、装饰线、水印）

#### 2. 版式布局（Slide Layout）
- 每页版式的占位符数量和位置
- 标题占位符、正文占位符、图片占位符、图表占位符的坐标和尺寸
- 内容区域的边距和排版规则

#### 3. 主题颜色（Theme Colors）
- 主色调（文字/背景/强调色1-6）
- 超链接颜色（未访问/已访问）
- 颜色方案的完整映射表

#### 4. 字体方案（Font Scheme）
- 标题字体（西文/中文）
- 正文字体（西文/中文）
- 字号层级（主标题/副标题/正文/注释）
- 字体颜色（自动/固定色）

#### 5. 背景样式（Background Styles）
- 纯色背景（颜色值）
- 渐变背景（方向/色标/透明度）
- 图片背景（图片路径/平铺方式/透明度）
- 纹理背景（纹理类型/前景色/背景色）

#### 6. 图形样式（Shape Styles）
- 默认形状填充（颜色/渐变/图片/纹理）
- 默认形状边框（颜色/粗细/线型）
- 阴影效果（偏移/模糊/颜色/透明度）
- 圆角半径

#### 7. 表格样式（Table Styles）
- 表头样式（填充色/字体/边框）
- 奇偶行样式（斑马纹颜色）
- 边框样式（颜色/粗细）

#### 8. 图表样式（Chart Styles）
- 默认配色方案（系列1-6颜色）
- 图表背景（填充/边框）
- 坐标轴样式（颜色/粗细/刻度）
- 数据标签样式（字体/颜色/位置）

### 第三步：内容迁移与样式融合

#### 内容迁移规则

1. **文本内容迁移**：
   - 提取A-PPT每页的标题文本 → 放入B-PPT对应版式的标题占位符
   - 提取A-PPT每页的正文文本 → 放入B-PPT对应版式的正文占位符
   - 提取A-PPT每页的要点列表 → 保持层级结构迁移
   - 保留原文本的超链接

2. **图片迁移**：
   - 提取A-PPT中的图片文件 → 按原尺寸比例放入B-PPT的图片占位符
   - 如果B-PPT版式无图片占位符 → 在内容区域中央放置，保持原尺寸比例
   - 保留图片的裁剪信息（如有）

3. **图表迁移**：
   - 提取A-PPT中的图表数据 → 在B-PPT中重建同类型图表
   - 应用B-PPT的图表配色方案
   - 保留图表标题和数据标签

4. **表格迁移**：
   - 提取A-PPT中的表格数据 → 在B-PPT中重建表格
   - 应用B-PPT的表格样式（表头/斑马纹/边框）
   - 保持行列结构和合并单元格

5. **SmartArt/图形迁移**：
   - 提取A-PPT中的SmartArt文本内容 → 在B-PPT中重建同类型SmartArt
   - 应用B-PPT的图形样式（填充/边框/阴影）

#### 样式融合规则

1. **文本样式融合**：
   - 标题文本：应用B-PPT的标题字体、字号、颜色、加粗/斜体
   - 正文文本：应用B-PPT的正文字体、字号、颜色、行距
   - 保留A-PPT中的文本特殊格式（下划线、删除线、高亮）
   - 如果A-PPT文本颜色是强调色 → 映射到B-PPT对应强调色

2. **形状样式融合**：
   - A-PPT中的自定义形状 → 应用B-PPT的默认形状样式
   - A-PPT中的文本框 → 应用B-PPT的正文样式
   - 保留形状的几何变换（旋转/翻转/组合）

3. **颜色映射**：
   - 建立A-PPT主题颜色 → B-PPT主题颜色的映射表
   - A-PPT中使用主题颜色的元素 → 按映射表替换为B-PPT对应颜色
   - A-PPT中使用自定义颜色的元素 → 保留原色（不强制替换）

4. **背景应用**：
   - 每页应用B-PPT对应版式的背景样式
   - 如果B-PPT版式背景继承母版 → 应用母版背景

### 第四步：输出与保存

1. 生成新的PPT文件，命名规则：`[A-PPT文件名]_美化.pptx`
2. 校验输出：
   - 页数与A-PPT一致
   - 所有文本内容完整迁移
   - 所有图片/图表/表格存在且可正常显示
   - 样式与B-PPT模板一致
3. 保存到用户指定位置或当前工作空间
4. 向用户汇报迁移统计：
   - 总页数
   - 迁移的文本框数量
   - 迁移的图片数量
   - 迁移的图表数量
   - 迁移的表格数量
   - 应用的版式名称

## 输入与输出规范

| 项目 | 规范 |
|------|------|
| 输入格式 | 两个 .pptx 文件（A-PPT内容源 + B-PPT模板源） |
| 输出格式 | 一个 .pptx 文件 |
| 输出命名 | `[A-PPT文件名]_美化.pptx` |
| 兼容性 | Office 2016+ / WPS / Google Slides |

## 注意事项

- A-PPT和B-PPT的页数不同时，需要用户确认版式映射策略
- 复杂动画效果默认不迁移，如需迁移需用户明确指定
- 嵌入的视频/音频文件默认迁移，但需确认文件路径有效性
- 字体缺失时自动替换为系统默认字体，并在报告中标注
- 如果B-PPT使用特殊字体且用户系统未安装，输出文件可能显示异常
- A-PPT中的自定义VBA宏默认不迁移

## 禁止事项

- 不修改A-PPT的原始文件
- 不修改B-PPT的原始文件
- 不遗漏A-PPT的任何内容（文字、图片、图表、数据）
- 不编造B-PPT中不存在的样式
- 不强制改变内容逻辑结构（仅改变视觉呈现）

## 故障处理

| 问题 | 处理方式 |
|------|---------|
| A-PPT页数 > B-PPT版式数 | 提示用户选择：循环使用版式 / 使用母版默认版式 |
| B-PPT使用特殊字体 | 标注缺失字体清单，建议用户安装或使用替代字体 |
| A-PPT含不支持的元素（如3D模型） | 保留原元素，标注未套用样式 |
| 图片尺寸与占位符不匹配 | 保持比例缩放，居中放置，不拉伸变形 |
| 表格数据量超出B-PPT版式容量 | 缩小字号或调整列宽，保持数据完整 |
