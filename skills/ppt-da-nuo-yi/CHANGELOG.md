# Changelog

All notable changes to this skill will be documented in this file.

## [1.0.0] - 2026-09-27

### Added

- 初始版本发布
- 支持双PPT输入：A-PPT（内容源）+ B-PPT（模板源）
- 八维度样式迁移：母版、版式、主题颜色、字体、背景、图形、表格、图表
- 内容完整迁移：文本、图片、图表、表格、SmartArt
- 颜色映射系统：A-PPT主题色自动映射到B-PPT对应颜色
- 页数不匹配处理策略：循环使用版式 / 使用母版默认版式
- 字体缺失检测与替代方案
- 迁移统计报告生成
- 故障处理机制：特殊元素标注、比例保持、数据完整性保障
