# PPT大挪移 - PPT Style Transfer

> 将一个PPT的内容完整迁移到另一个PPT的模板样式中，实现一键美化。

## 这是什么

PPT大挪移是一个 WorkBuddy 技能（Skill），用于将"内容PPT"的文字、图片、图表、数据等内容，完整迁移到"模板PPT"的视觉样式中。保留原PPT的所有内容，同时套用模板PPT的版式、配色、字体、背景等视觉设计。

## 使用场景

- 你有一个内容很好的PPT，但版式老旧、配色丑、字体不统一
- 你找到了一个设计精美的PPT模板，想把内容套进去
- 团队有统一的视觉规范模板，需要把不同人做的PPT统一风格
- 快速批量美化多个PPT，保持品牌一致性

## 安装

### 方式一：手动安装

1. 下载并解压 ZIP 包
2. 将 `ppt-da-nuo-yi` 文件夹复制到 WorkBuddy 技能目录：
   - **Windows**: `C:\Users\你的用户名\.workbuddy\skills\`
   - **macOS**: `~/.workbuddy/skills/`
3. 重启 WorkBuddy

### 方式二：WorkBuddy 内导入

1. 打开 WorkBuddy → 技能管理 → 本地技能
2. 将 `ppt-da-nuo-yi` 文件夹拖入窗口
3. 等待校验完成

### 方式三：分享给其他用户

将本 ZIP 包直接发送给对方，对方按"方式一"安装即可。

## 使用方法

安装完成后，在 WorkBuddy 对话中：

1. 同时上传两个PPT文件：
   - **A-PPT**：你的内容PPT（美观度一般）
   - **B-PPT**：你的模板PPT（设计精美）

2. 说：**"把A的内容套到B的模板里"** 或 **"PPT大挪移"**

3. 技能会自动：
   - 提取B-PPT的母版、版式、配色、字体、背景、图形样式
   - 将A-PPT的所有内容（文字、图片、图表、表格）迁移到新版式中
   - 输出美化后的新PPT文件

### 样式迁移维度

| 样式维度 | 迁移内容 |
|---------|---------|
| 幻灯片母版 | 背景、占位符布局、固定图形（Logo/装饰线） |
| 版式布局 | 标题/正文/图片占位符的位置和尺寸 |
| 主题颜色 | 主色调、强调色、超链接颜色 |
| 字体方案 | 标题字体、正文字体、字号层级 |
| 背景样式 | 纯色/渐变/图片/纹理背景 |
| 图形样式 | 形状填充、边框、阴影、圆角 |
| 表格样式 | 表头、斑马纹、边框 |
| 图表样式 | 系列配色、坐标轴、数据标签 |

## 输出示例

```
输入：
├── A-PPT（内容源）— 50页，内容完整但配色混乱
└── B-PPT（模板源）— 30页，设计精美

输出：
├── A-PPT_美化.pptx — 50页，A的内容 + B的样式
└── 迁移报告：
    ├── 总页数：50
    ├── 迁移文本框：120个
    ├── 迁移图片：45张
    ├── 迁移图表：12个
    ├── 迁移表格：8个
    └── 应用版式：封面/目录/正文/图表/总结 等5种
```

## 注意事项

- A-PPT和B-PPT的页数不同时，技能会提示你确认版式映射策略
- 复杂动画效果默认不迁移，如需迁移需明确告知
- 嵌入的视频/音频文件会迁移，但需确认文件路径有效性
- 如果B-PPT使用特殊字体且你的系统未安装，输出文件可能显示异常（会在报告中标注缺失字体清单）
- A-PPT中的自定义VBA宏默认不迁移
