# 成果版式（output-layout）

PDF / PPT 不是"把文字排上去"，而是**让一页纸看起来像一个产品**。本文件固定精益建造成果的版式参数，
换板块可以换颜色，**分段位置不要随意改**——改了线条就跨卡不对齐。

---

## 一、卡片结构（自上而下四段）

```
┌──────────────────────────────────────────┐
│ ① 优化措施名称（蓝底白字通栏标题条）        │  TITLE_H ≈ 34pt
├──────────────────────────────────────────┤
│ ② 优化内容（浅蓝标签 + 正文）              │  占正文区 60%
│    ▏蓝字小标签「优化内容」                  │
├──────────────────────────────────────────┤
│ ③ 优化效果（浅蓝标签 + 浅蓝底正文）         │  占正文区 40% 中的剩余
│    ▏蓝字小标签「优化效果」                  │
├──────────────────────────────────────────┤
│ ④ 实体案例（标签 + 图片，按框缩放）          │  图片区 ≈ 正文区 33%
└──────────────────────────────────────────┘
```

对应 `lean_pdf.py` 的 `rowHeights=[TITLE_H, h1, h2, IMG_LABEL_H, img_h]`。

## 二、关键参数（改了要重新验证页数与对齐）

| 常量 | 值 | 作用 |
|---|---|---|
| `TITLE_H` | 34 | 标题条高 |
| `SEC1_RATIO` | 0.60 | 优化内容占正文区比例（其余给优化效果） |
| `IMG_RATIO` | 0.33 | 图片区占整卡高度比例 |
| `IMG_LABEL_H` | 30 | 「实体案例」标签行高（26 时标签贴图太紧） |
| `SEP` | 1.1 | 分段间距 |
| `FS_MAX / FS_MIN` | 10.2 / 6.4 | 正文字号上下限，按内容长度自适应 |

## 三、配色（取自样板截图，逐像素取色）

| 用途 | 色值 |
|---|---|
| 标题条底 / 分段线 / 强调 | `#4F81BD` |
| 浅色底（优化效果区、表头） | `#C6D9F1` |
| 小标签文字 | `#0070C0` |
| 正文 | `#333333` |

## 四、让线条跨卡对齐的唯一方法

不要"每张卡按内容高度自己算"——那样每段高度都不同，两卡叠一起就参差。

做法：**先统一算三段高度，再逐卡填内容**。

```
正文区总高 H_body = 页可用高 - 标题区 - 图片区 - 分段线
h1 = H_body * SEC1_RATIO          # 优化内容
h2 = H_body * (1 - SEC1_RATIO)    # 优化效果
img_h = 卡高 * IMG_RATIO          # 图片区
```

图片再按框缩放：`box_h = row_h - 14`（上下各留 7pt），等比缩放到框内、居中。

**校验方法**：渲染成图后用 PIL 逐行扫描深色横线，确认多张卡的横线 y 坐标一致
（本项目核对为 Y = 46 / 119 / 466 / 696 / 754 / 1102，完全对齐）。

## 五、字号自适应

```
按字数估算：fs = clamp(FS_MAX - (字数 - 120) * 0.008, FS_MIN, FS_MAX)
```

内容长的条目自动缩到 6.4pt，仍放不下就截断并加「…」，**不允许溢出到下一段**。

## 六、表格型分段线怎么画

reportlab 的 `Table` 用 `LINEBELOW` 在指定行下画线，比手画 `Line` 更稳（跟随行高，不漂）：

```python
TableStyle([
    ('LINEBELOW', (0, 0), (-1, 0), 1.0, colors.HexColor('#4F81BD')),   # 标题条下
    ('LINEBELOW', (0, 1), (-1, 1), 0.6, colors.HexColor('#4F81BD')),   # 优化内容下
    ('LINEBELOW', (0, 2), (-1, 2), 0.6, colors.HexColor('#4F81BD')),   # 优化效果下
])
```

文字里的 `& < >` 必须 `xml.sax.saxutils.escape()`，否则 `Paragraph` 解析报错。

## 七、PPT

走集团模板（`data/ppt_builder/build.py` + `集团模板.pptx`），一个点子一页、每章一个目录页。
构建器必须**随 data 一起打包**并在进程内调用（见 pitfalls 第 25 条）。

版式核对顺序：目录页 → 首页 → 抽查 3 页（最长内容 / 最多图 / 单图）。
长内容页最容易溢出，一定要看。
