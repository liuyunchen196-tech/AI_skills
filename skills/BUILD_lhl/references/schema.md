## 一之二、适用部位用词规范

`适用部位` 既用于筛选，也用于查重（同部位才比做法），**同义异写必须先归一**，否则查重直接漏掉。

| 规范写法 | 常见异写 | 说明 |
|---|---|---|
| 公共区域 | 公共区、公区 | |
| 管道井 | 管井 | 水暖井、电井单列，不并入 |
| 电梯井 | 电梯井道 | 与「电梯」分部区分：这是井道土建/预留 |
| 地下室 | 地下层、负层 | 带具体层号时可写「地下一层」 |
| 标准层 | 楼层、各层 | 「全楼层」是另一档，别混 |
| 外立面 | 外墙、外墙面 | 与「外墙」在防水类条目里可互换，统一取「外墙」 |
| 首层 | 一层、底层 | |

> 归一动作要**只改词、不改条目**：`适用部位` 里的 `、` 分隔项去重后按原序重组，
> 并保留原值到 `别名`（若整条只有一个部位被改，可省略）。本项目一次性修正 12 条。

## 三、信息词条（核心检索字段）

**定义**：一条措施的自然语言检索标签集，分号 `;` 分隔，3~8 个，用于前端搜索、
相似措施推荐、跨板块匹配、以及后续大模型语义检索的锚点。

### 生成规则（按优先级取，去重后截断到 8 个）

1. **核心对象**：措施名去掉通用后缀（`施工工艺/工艺/工法/技术/施工/应用/高效工艺`）后的主体词
2. **动作/做法**：`一次成型`、`预埋`、`免抹灰`、`免开槽`、`永临结合`、`模块化`、`预制拼装`、`免吊洞`
3. **材料/构件**：`铝模`、`PP-R`、`U-PVC`、`止水节`、`套管`、`线盒`、`桥架`
4. **部位**：取 `适用部位`（去掉顿号拆开）
5. **分项工程**名

### 示例

| 措施 | 信息词条 |
|---|---|
| 三段式止水螺杆施工工艺 | `三段式止水螺杆;止水螺杆;地下室外墙;防水;模板加固` |
| 全现浇外墙免抹灰施工工艺 | `全现浇;外墙;免抹灰;一次浇筑;渗漏` |
| 楼层消火栓永临结合施工工艺 | `消火栓;永临结合;临时消防;室内给水系统;全楼层` |

### 约束

- 不写空泛词：`施工`、`工程`、`优化`、`做法`、`技术` 不入词条。
- 不写数字序号。
- 同一措施内不得重复；全角分号不带空格。
- 检索时按 `;` 切分后做包含匹配；不要对整串做全文匹配。

## 六、派生字段计算口径

### 适用楼层

```
地上层数 N，单层层高 H，适用部位 P：
  P 含「地下」→ 地下 1~M 层（M = 地下层数）
  P 含「屋面/外墙/外立面」→ 全部楼层
  P 含「首层/一层」→ 1 层
  P 含「标准层/全楼层」→ 2~N 层
  其它 → 全楼层
```

### 实体案例（原「效果示意」列）

取该条 `图片` 数组，映射到 `图片库\<文件名>`，用 `;` 拼接。
上限 6 张（PDF 一页放 6 张，超过走三列缩略）。
