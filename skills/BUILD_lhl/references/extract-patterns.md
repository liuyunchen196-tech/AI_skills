# 版式提取要点（extract-patterns）

四类版式已全部实战验证。**先 `probe.py` 体检，再对号入座**；判断错版式 = 白做。

---

## 版式 A · 矢量框线表格

**识别特征**
- 文本层完整、可读
- `page.get_drawings()` 能取到大量矩形/线段，表格有明显竖线与横线
- 例：`精益建造指导手册-房屋建筑分册终稿.pdf`（13 张表）

**提取方法**
1. 收集所有 `get_drawings()` 的线段，竖线取 `x`、横线取 `y`
2. 竖线按 `x` 聚类 → 列边界（通常 5~6 列）
3. 横线按 `y` 聚类，**要求线段跨度覆盖表格整宽**，否则是表内局部线 → 得到行边界
4. 文本按 `bbox` 中心点落入 (行, 列) 单元格
5. 跨页表：同表续页表头重复出现，按表号合并

**坑**
- `page.find_tables()` 在这类表上**完全不可用**（合并单元格 + 跨页乱序），别浪费时间
- 页眉横幅图（约 `bbox(76,54,257,76)`）必须排除，否则会被当成内容图
- 表格线有粗细两条重合，聚类容差取 2~3pt

## 版式 B · 卡片式（横版幻灯片）

**识别特征**
- 页面横版（如 960×540 或 A4 横）
- 每页 1~3 张卡片，卡片有蓝色标题条
- 卡片内固定小标签：`实施效果` / `工艺要点` / `实体案例`
- 例：`中建三局精益建造指导手册.pdf`（48 页）

**提取方法**
1. 按 `♦/◆` 标签的 `y` 分槽位；同列内按 `y` 递增归属卡片
2. 标题 = 页面上第一个标签之上、页眉之下的文本
3. 每张卡片的图片 = y 落在「实体案例」段内、且 x 落在本栏范围的 image

**L 型排版（左 1 右 2）**
- 一页 3 张卡时，常见布局是「左栏 1 张大卡（占满高）+ 右栏 2 张上下排列」
- **必须按栏归属**：先按 x 切左右栏（分界约 `page.width/2`），再在栏内按 y 切卡片
- 只按 y 切片会把左右两栏的内容混进同一张卡 → 字段全错

**坑**
- 蓝色标题条是**背景图**（宽≈429pt、高≈40pt），不排除会被当成效果图
- 卡片的图可能跨 y 略有溢出，取「段落 y 起点 −4pt」作为下界更稳
- 一页只有 1 张卡时，右栏无标签，别强行凑

## 版式 C · A3 横排多表（含扫描件）

**识别特征**
- 一页 1 张表，多列表头（如 `序号/分项/案例名称/案例简述/实施目的/图片`）
- 文本层可能**乱码**（字体缺 ToUnicode，`get_text()` 出来是方框/怪字符）
- 例：`三局优化建议2.0.pdf`（20 页 / 10 张表）

**提取方法（有文本层）**
1. 竖线定列 → `COLS = [x1, x2, ...]`
2. 横线按 y 间距聚类分行；间距 > `max(中位数×2, 110)` 视为换表
3. 单元格文本按 bbox 落格

**提取方法（乱码 / 扫描件）**
1. 300dpi 渲染整页 PNG
2. RapidOCR 识别（`text_score=0.3, box_thresh=0.2`，否则单字行「化」会被吞）
3. 坐标换算 `pt = px × 72 / dpi`
4. 用框线坐标（来自 PDF 矢量，不依赖 OCR）做格网，把 OCR 结果落格
5. 「案例名称」列单独裁切、400dpi 重识别（名称最易丢末字）

**坑**
- 部分页 `/Rotate = 90/270`，图片坐标在**未旋转空间**。做法：对候选变换（原样/镜像/旋转）逐一试，取与框线最贴合的解
- OCR 的编号锚点（如 `1.3-2`）不能被「像正文段落」的规则误删，**含连字符的编号一律保留**
- `keep()` 过滤正文段落时用「宽度 > 135pt 剔除」，但编号行不受此限

## 版式 D · 双栏卡片（16:9）

**识别特征**
- 页面 960×540，每页固定 2 张卡，左右各一
- 卡片结构：标题 → `♦实施效果` → `♦工艺要点` → `♦实体案例` + 图
- 例：`优化工艺.pdf`（32 页 / 64 卡 / 128 图）

**提取方法**
1. 分界 `SPLIT_X = 480`，按 x 切左右栏
2. 每栏取 `♦` 标签按 y 排序，相邻标签之间为一段
3. 段内文本按 `y` 升序、`x` 升序拼接
4. 图片筛选：`y1 > 100 且 y3 > 200 且 宽 > 50 且 高 > 60`（滤页眉横幅与 logo）
5. 实体案例段落 y 之后的图归该卡；该段无图则退化为本栏全部内容图

**字段映射特例（重要）**

```
图片上的「实施效果」 → 库「优化效果」
图片上的「工艺要点」 → 库「实施效果」
```

**坑**
- 宽度阈值设 80pt 会漏掉窄图（有 72pt 的案例图），放到 50pt；过滤靠 y 坐标而不是宽度
- 标题字号不统一（长标题会被缩小到 12pt），**按位置判断标题，不能按字号**
- 文本断行拼接：行尾是标点或行首是序号（`1、`、`2、`）直接相接，其余按需补空格；
  OCR 常见 `2 、` 这种「数字+空格+顿号」，归一成 `2、`

## 通用文本归一（所有版式都要过一遍）

```python
def norm(s):
    s = s.replace('\u3000', ' ').replace('\xa0', ' ')
    return re.sub(r'\s+', '', s).strip()
```

- 中文**不加空格**拼接；英文/数字之间才补空格
- 句子级去重：按 `；;。` 切分，去重后按原序重排（修过「优化效果重复 4 次」的脏数据）
- 去掉标签前缀：`实施效果`、`工艺要点`、`实体案例`、`案例名称`、`分项`
